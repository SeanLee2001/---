# 屏幕题库助手

Windows 桌面工具：框选电脑上的手机投屏画面（建议使用向日葵），定时识别题干和选项，检索本地题库，显示相似题、答案及解析。

此版已增强模糊匹配，识别出的题目无需与题库完全一致。可以容忍少量错字、漏字、多字、部分语序变化与常见问法差异，也可以输入题干片段搜索。主要技术词和含义仍需有足够重合；完全换一种说法时，候选可能不准确。

已用这份题库验证的示例：“电流速段保护是？”、“电流速断保护”、“电力系统出现振荡时，哪种保护可能误动？”、“两相两继电器的不完全星形接法能反应什么故障？”。这些文本与原题不同，仍能检索到对应题目。

更新旧版时，关闭程序，将新版文件解压覆盖原软件文件夹即可；原有 `题库缓存.json` 可以保留。

## 开始使用

1. 将压缩包**完整解压**到可以写入的文件夹，例如桌面的“屏幕题库助手”。不要直接在压缩包中运行。
2. 双击 `屏幕题库助手.exe`。## 导入更多 Excel 题库
3. 将手机投屏到电脑，并打开一道题。点击“框选屏幕区域”，拖动框选题干及选项；按 Esc 或右键可以取消。
4. 把软件窗口放到框选区域外，点击“开始实时识别”。也可以最小化软件以避免遮挡。
5. 左侧显示 OCR 文字和最多五道相似题，右侧显示选中的题库题目、答案、对应选项内容及解析。点击候选行可切换题目。

默认检查间隔为 1.2 秒；OCR 耗时取决于截图大小、文字量和电脑性能。上一次识别未完成时不会叠加新任务，因此检查间隔不等于保证的出答案时间。相同画面会跳过重复 OCR。画面变化、空白或识别失败时，会清除此前的答案。

## 导入更多 Excel 题库

点击“导入 Excel”，选择 `.xlsx` 文件，在预览窗口确认工作表、表头行、题目、答案、解析和各选项对应列，然后导入。

- 已适配本次提供文件的列：题干、选项A～G、答案、解析；序号、题型、分值、难易度不影响匹配。
- 每次导入一个工作表；可重复导入其他工作表或文件，合并为一个题库。重复导入相同文件也会合并，请避免重复操作。
- 题目列必选；答案、解析及选项列可以留空。未提供答案的题会明确显示“题库未提供”。
- 新导入的题库会保存在软件旁的 `题库缓存.json` 中，下次启动会恢复。清空题库也会保存；若想恢复随包原始题库，关闭软件后删除这个缓存文件即可。
- 旧版 `.xls` 请在 Excel 中另存为 `.xlsx`。另支持 UTF-8 编码的 CSV 和 TSV。
- 每个文件最多 100 MB，每个工作表最多 20 万行。公式单元格应在 Excel 中计算并保存，或粘贴为值后导入。

## 提高匹配效果

- 框选一题的完整题干和选项，尽量避开倒计时、顶部导航、滚动列表及其他题目。
- 投屏文字应清晰、完整。若文字较小，可以勾选“小字放大”；放大后 OCR 可能变慢。
- 移动投屏窗口、改变分辨率或调整显示器布局后，重新框选。
- 匹配分数为文字相似度，**不是答案正确率**。默认下限为 45，可以根据候选结果调整。
- 相近题干、否定词、数字和选项差异都可能影响结果。请核对候选的完整题目和选项。
- 答案来自你提供的题库。若投屏端打乱了选项顺序，请按“对应选项内容”查找，不要直接照搬题库的 A/B/C 字母。
- 可手动输入题干片段并按 Enter 搜索；手动搜索会暂停实时识别。至少输入四个有效文字或数字。

## 本地运行与环境

程序与 OCR 在本机运行，不调用云端识别服务，不上传截图和题库。识别时只暂存当前截图，任务结束后删除；异常强制结束时若留下 `.cache-*.png`，可在关闭软件后删除。

需要 Windows 10/11、.NET Framework 4.8（或兼容的 4.x）、Windows PowerShell 5.1 和 Windows 中文 OCR 语言功能。本机已实测中文 OCR 可用。程序不需要 Python、Excel 应用程序或 API 密钥。

`ocr-worker.ps1` 必须与 exe 放在同一目录。程序会在隐藏窗口中运行它，仅对该进程使用 ExecutionPolicy Bypass，不更改系统的 PowerShell 执行策略。如果受组织策略限制，界面会显示识别错误。

如提示缺少 OCR 语言，请到 Windows“设置 → 时间和语言 → 语言和区域”检查简体中文及其光学字符识别功能。



技术参考：[Microsoft Windows OCR API](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine)。
